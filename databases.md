# Enhancement Three: Databases

## Artifact Overview

**Artifact:** CS 340 Grazioso Salvare MongoDB Dashboard  
**Course:** CS 340: Client/Server Development  
**Category:** Databases

The original dashboard connected a Dash/JupyterDash interface to the Austin Animal Center Outcomes MongoDB database through a reusable Python CRUD module.

## Enhancement Summary

The enhanced version improves the MongoDB data layer with allowlisted query fields, result caps, safer write operations, configuration separation, reusable rescue filters, index support, sample queries, mocked unit tests, and optional live MongoDB integration testing.
